# Changelog

All notable changes are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/) and versions follow semver;
`melos version` drives releases from conventional commits.

## 0.4.0

- **Additive change**: add typed extension message frame models in `frames.dart`
  — `HelloFrame`, `CallFrame`, `CallResultFrame`, `CallErrorFrame`,
  `CancelFrame`, and `EventFrame` — generated with schemantic. Each carries a
  `kind` discriminator with the wire strings the host and SDK already use
  (`hello`/`call`/`call.result`/`call.error`/`cancel`/`event`); `EventFrame`
  wraps a serialized `AgentEvent`. The extension reply `SendPort` stays a native
  field outside `HelloFrame` (ADR-0022).

## 0.3.0

- **Additive change**: add `observes` (`List<String>`, default empty) to
  `ExtensionProvides` and `ExtensionManifest`, the state topics an extension
  observes (docs/spec/contracts.md, §10.5).
- **Additive change**: promote `StateTopic` from `runtime/core` into this
  package (`state_topic.dart`); the enum values are unchanged.
- **Additive change**: add `canonicalJson`, the shared canonical-JSON encoder
  (sorted keys, no insignificant whitespace, `signature` excluded) used to sign
  and verify an extension manifest.
- `ExtensionManifest` and `ExtensionProvides` are now generated with
  schemantic; the manifest JSON Schema is generated by `build_runner`. The JSON
  shape is additive-only.

## 0.2.0

- **Additive change**: add `ServerInfo`, the `/v1/info` DTO carrying
  `protocolVersion`, `sdk`, and `capabilities` (docs/spec/api.md, §16.3).
  Generated with schemantic; the additive-only JSON shape is unchanged for
  existing types.

## 0.1.0

- **Breaking change**: the minimum Dart SDK is now `^3.14.0` (raised from `^3.13.0`).

## 0.0.1

- Initial scaffold: package metadata, workspace integration, and documentation.
  No functional implementation yet.
