# Trademark policy

The Apache-2.0 license grants broad rights to the **code**, but it does not grant rights to the **name**. This document is a short policy on using the name AlteriOne and the alteri.one domain.

## What is protected

The name **AlteriOne**, the binary name **`alterione`**, and the alteri.one domain identify binaries and distributions produced by this project.

## What you may do without asking

- State truthfully that your project builds on, uses, or is compatible with AlteriOne.
- Refer to AlteriOne by name in articles, reviews, talks, and documentation.
- Fork the repository and modify the code, provided you rename the resulting product and binary so it is clear they are not produced by this project.

## What requires permission

- Distributing a modified or unmodified binary **under the name AlteriOne** or as `alterione`.
- Using the name in a way that implies endorsement by, or affiliation with, this project.

The spec's "personal builds" mechanism (`distribution.yaml`) intentionally gives every personal build its **own name** for exactly this reason; see `docs/spec/product.md`, section 1.

Questions about the name: open a [discussion](https://github.com/dip-develop/alteri-one/discussions) or write to the address in [SECURITY.md](SECURITY.md) with "trademark" in the subject.
