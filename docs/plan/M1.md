Toolchain findings recorded in `docs/spec/open-questions.md`:

- Q5: `public_member_api_docs` cannot see primary-constructor parameter docs
  on SDK 3.13.5 — lint omitted from the shared set, docs stay mandatory by
  convention.
- Q6: the compiler's verified `new` constructor forms differ from the
  section 7.3 examples (space, not dot; type-less named factories; no named
  `new` factories). Code follows the compiler.
- T21: bloc 9 runs each `on<E>()` as a separate subscription, so per-handler
  `sequential()` does not order events across types. The composition root
  sets `Bloc.transformer = sequential()` once (`applyBlocDefaults()`), and
  `RunBloc`/`ApprovalsBloc`/`ExtensionsBloc` use a single handler with an
  exhaustive `switch` over their sealed event types. Section 8.10 rule 4
  should be rewritten; an ADR can record the pattern.
