# Architecture decision records (ADR)

Each significant decision is recorded in a separate numbered file: `NNNN-short-name.md`.

- Status: `Proposed`, `Accepted`, or `Superseded by NNNN`.
- An accepted ADR is never edited. To change a decision, write a new ADR and mark the old one as `Superseded by NNNN`.
- Template: `0000-template.md`.
